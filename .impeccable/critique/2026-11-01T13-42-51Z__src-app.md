# Soul Ledger: critique and audit, all pages at desktop 1440, tablet 834 and phone 390

How this was run: three separate reviewers, kept apart from each other. One did the design critique, one ran the automated checker on the rendered pages, and one did a technical audit. They used a production build on live API data, viewed in headless Chrome.

Scores: Design 26/40 (Acceptable, close to Good). Technical audit 14/20 (Good). Blocking issues: 0. Major issues: 10.

## 1. Accessibility and broken layouts
1. [Major] Match, all sizes: the Souls-lead chart shows no outline when it has keyboard focus (src/components/charts/SoulsLeadChart.tsx:117). Fix: use outline-hidden or focus-visible:outline-solid.
2. [Major] Match, all sizes: the 15 objective rows are each a stop when tabbing through the page, and focused rows only get a faint tint, about 1.08:1 (src/components/match/ObjectiveList.tsx:181-189). Fix: give them a visible outline, or make the list a single tab stop.
3. [Major, CONFLICT] Meta, all sizes: matchup-grid cell numbers fail contrast at 2.7–4.4:1. The charts skill sets the text-colour switch at |v|>2.6 (src/components/charts/MatchupGrid.tsx:5-13).
4. [Major] Match, desktop and tablet: Damage-share labels fail contrast at 3.1–4.3:1 (src/components/charts/DamageShare.tsx:46,126).
5. [Major, CONFLICT] Match, all sizes: sold build items are faded to opacity 0.5, so their text drops to 2.4:1. The skill says sold items are "dimmed" but also requires 4.5:1 contrast (src/components/match/BuildOrder.tsx:47-48).
6. [Major] Match and Player, tablet and phone: chart labels are sized inside the SVG and shrink with it. Souls-lead labels end up 6–10 px and The climb labels 6.5–9.5 px (src/components/charts/SoulsLeadChart.tsx:137-150,226-238; RankClimb.tsx:108).
7. [Major, CONFLICT] Meta, all sizes: Where players rank labels are 8–9 px. The MetaMobile design specifies 8/9 px; the skill says 10–11 (src/components/charts/RankDistribution.tsx:35,48).
8. [Major] Match, desktop and tablet: columns in the two scoreboard team tables don't line up (src/components/match/Scoreboard.tsx:32).
9. [Minor] All pages: the default focus ring is a thin 50% brass. The phone rank filter uses a 30% brass ring, and the Items tab panel has none (src/app/globals.css:128; ui/tabs.tsx:83).
10. [Minor] All pages: there is no skip link (src/app/layout.tsx:56).
11. [Minor] Live and Match, tablet: some label text is 10 px, below the 11–12 px scale.
12. [Minor] Match, Meta, Player and /players: some tap targets are under 44 px. Breadcrumb 46×14, Pick 30×16, scoreboard names 16 px tall, history hero links 28 px, Recent search chips 36 px.
13. [Minor] Meta, Match, /players and Player: text is cut off with no way to read all of it. Matchup labels, a damage segment, the search-result details line on phone, and long player names.
14. [Minor] /players and Live: screen readers don't hear the search result count, don't hear when a live match ends, and get very long names for card links.
15. [Minor] Match and Live: the DamageShare and PickedNow charts give screen readers a single sentence instead of the full breakdown.
16. [Polish] Meta and Match, at 1280–1365 px: tables that can scroll sideways can't be scrolled with the keyboard.
17. [Polish] Live: the live dot may keep pulsing when reduced motion is on (src/components/live/live-client.tsx:113-120).
18. [Polish] /players: the search box focuses itself on page load (src/components/players/PlayerSearch.tsx:134-137).
